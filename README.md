# On Par Entertainment — Waitlist

Live waitlist for **bowling**, **darts**, **pool**, and **shuffleboard**.

| Piece | Location |
|--------|----------|
| **Next.js app** | `web/` — deploy this folder to Vercel |
| **Xcode app** | `On Par Waitlist/` |
| **Deploy guide** | [DEPLOYMENT.md](./DEPLOYMENT.md) |

## Local development

```bash
cd web
npm install
npm run dev
```

## Vercel

Import the repo and set **Root Directory** to **`web`**. See [DEPLOYMENT.md](./DEPLOYMENT.md).
