# On Par logo

Drop your logo here to show it at the top of the waitlist.

## Quick setup

1. Add your logo file to this folder as one of:
   - `on-par-logo.png` (recommended — transparent background)
   - `on-par-logo.svg`
   - `on-par-logo.webp`

2. If you use a **different filename**, open `src/components/Logo.tsx` and change `LOGO_SRC`.

## Tips

- **PNG or SVG** with a transparent background looks best on the dark header.
- Recommended height: about **36–48px** (width can vary).
- After replacing the file, refresh the page (hard refresh on phone if needed).

The placeholder `on-par-logo.svg` is shown until you replace it.
